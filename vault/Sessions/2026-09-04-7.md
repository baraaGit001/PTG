# 2026-09-04-7

## Did
- Replaced the product page's flat image handling with a proper viewer.
  `packages/ui/src/composite/image-lightbox.tsx` is a new shared full-screen
  viewer (Radix Dialog): prev/next buttons, ←/→ keys, an `n / total`
  counter, a thumbnail rail, and a click-to-zoom toggle that swaps
  `object-contain` for a 160%-wide scrollable image. Exported from
  `packages/ui/src/index.ts`.
- `apps/web/src/features/marketplace/product-page.tsx`:
  - Gallery: hover arrows + counter on the main image, click opens the
    lightbox on that index, thumbnails now a scrollable rail with a 2px
    active border. Lightbox navigation keeps `activeImage` in sync so
    closing it leaves the page on the image you were looking at.
  - "Product Details": the DETAIL images were rendered as one endless
    stack. They now collapse to 520px with a gradient fade and a
    "Show all N images" toggle, and each panel opens the same lightbox.
- New `marketplace.*` keys (`viewFullImage`, `previousImage`, `nextImage`,
  `imageCount`, `showAllImages`, `showLessImages`) in all five locales.
  They interpolate `{{value}}`, not `{{count}}`, to stay off i18next's
  plural-key lookup — same convention as `pvValue`.

## Decided
- One lightbox component serves both image roles rather than two bespoke
  viewers; the page just tracks `{ source: 'gallery' | 'detail', index }`.
  Not ADR-worthy.
